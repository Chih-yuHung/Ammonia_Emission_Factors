Summary of Tier 2 NH3 Emission Factor Method

Author

Chih-Yu Hung

Overview

This report summarizes the proposed Tier 2 ammonia (NH3-N) emission factor outputs for animal housing and manure storage.

Housing emission factors are reported on a Total N basis and storage emission factors are reported on a TAN basis. Figures therefore compare patterns and relative magnitudes, but the denominator differs between the two stages.

Preparation

Read the results from housing and storage and MC results.

Note that we only have 4 board climate for housing, while 9 climate zones for storage.

There are 84 EFs for housing (21 animal/housing/manure combination x 4 climates) and 288 EFs for storage (8 animal/stroage/manure combination x 4 removal scenarios x 9 climates)

save_plot <- function(plot, file_name, width, height) {
  ggplot2::ggsave(
    filename = file.path(paths$figure_dir, file_name),
    plot = plot,
    width = width,
    height = height,
    dpi = 300,
    bg = "white"
  )
}

theme_tier2 <- function(base_size = 10) {
  theme_minimal(base_size = base_size) +
    theme(
      panel.grid = element_blank(),
      plot.title = element_text(face = "bold"),
      plot.subtitle = element_text(color = "#4f5963"),
      axis.title = element_text(face = "bold"),
      strip.text = element_text(face = "bold"),
      legend.position = "bottom"
    )
}

Figure 1. Housing EF Heatmap

The results used DATAMAN EFs as the reference EF and assumed the EFs were obtained at 15 C. CTs of Tied housing and deep litter were assumed same to Feedlot; CT of Layers in aviary house was assumed same to broiler; CTs of sows and pigelets were assumed same to finisher.

The housing heatmap shows a strong climate-temperature gradient, with highest values in the tropical zone and lowest values in the boreal zone.

Figure 2. Storage EF Heatmaps By Removal Schedule

Storage EFs are highest in warm climates and under less frequent removal, because TAN can accumulate and remain available during high-volatilization months. There is no CT for swine lagoon.

I found NH3 EF is not sensitive to removal frequency, unlike MCF. For instance, Dairy/manure heap/solid in tropical wet has 0.289 at single Oct removal, while 0.276 with three removals. I think it is because of high corrected EF that volatilized abundance of TAN before removal.

The annual NH3 EFs from storage was calculated as followed:

EF = Annual NH3 emissions / Total avaiable TAN in storage.

Figure 3. Monte Carlo Uncertainty Intervals

MC results showed the difference between deterministic EF and the mean of MC < 0.001 for housing and <0.01 for storage. However, wide ranges were observed in warm temperate and tropical regions as the exponential increase in EF under warm temperature.

Figure 4. EF Distribution Comparison

This summary highlights that storage EFs are generally larger than housing EFs, while also reminding that the basis differs: TAN for storage and Total N for housing.

The medium of EF could be used as Tier 1 EF?

Code 
housing_distribution <- housing_long %>%
  transmute(
    Stage_Group = "Housing",
    EF = EF_Deterministic
  )

storage_distribution <- storage_plot %>%
  transmute(
    Stage_Group = "Storage",
    EF = Year3_EF_TAN
  )

distribution_data <- bind_rows(housing_distribution, storage_distribution) %>%
  mutate(
    Stage_Group = factor(
      Stage_Group,
      levels = c("Housing", "Storage")
    )
  )


quantile_labels <- distribution_data %>%
  group_by(Stage_Group) %>%
  summarise(
    q25 = quantile(EF, 0.25, na.rm = TRUE),
    median = median(EF, na.rm = TRUE),
    q75 = quantile(EF, 0.75, na.rm = TRUE),
    .groups = "drop"
  ) %>%
  tidyr::pivot_longer(
    cols = c(q25, median, q75),
    names_to = "Statistic",
    values_to = "EF"
  ) %>%
  mutate(
    label = case_when(
      Statistic == "q25" ~ paste0(round(EF, 3)),
      Statistic == "median" ~ paste0(round(EF, 3)),
      Statistic == "q75" ~ paste0(round(EF, 3))
    )
  )


fig_distribution <- ggplot(distribution_data, aes(x = Stage_Group, y = EF)) +
  geom_boxplot(fill = "#d8ead2", color = "#2e4b3d", outlier.alpha = 0.5) +
  geom_jitter(width = 0.13, height = 0, alpha = 0.35, size = 1.1, color = "#a65b3b") +
  geom_text(
    data = quantile_labels,
    aes(x = Stage_Group, y = EF, label = label),
    inherit.aes = FALSE,
    nudge_x = 0.38,
    hjust = 0,
    size = 2.6,
    color = "#2e4b3d"
  ) +
  labs(
    title = "Distribution of deterministic Tier 2 emission factors",
    subtitle = "Housing is Total-N basis; storage is TAN basis",
    x = NULL,
    y = "EF, kg NH3-N / kg TAN or Total N"
  ) +
  theme_tier2(base_size = 9) +
  theme(
    axis.text.x = element_text(angle = 30, hjust = 1),
    plot.margin = margin(5.5, 35, 5.5, 5.5)
  ) +
  coord_cartesian(clip = "off")


fig_distribution
